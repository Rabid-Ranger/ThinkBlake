# Analytics updates: what to collect and why

Keep the current dashboard layout and original Diagnosis. Analytics supports a decision; it does not automatically rewrite the plan.

## First setup
Set the creator goal, intended audience, current strategy period, and each video's Reach / Trust / Convert job in the dashboard. Start with the 7d prompt and 10–20 previous comparable uploads when available. Five to nine observations give a limited working baseline; fewer remain provisional. These are coaching rules, not YouTube thresholds. Keep flops and outliers unless format, paid traffic, era or another structural difference makes them incomparable.

## Regular use
1. Select the checkpoint you want to review, normally 7d.
2. Studio prompts → Routine update → Copy prompt. Paste into Ask Studio for the correct channel.
3. Paste Studio results → Review imported data. Check channel, dates, lifespan, filters, definitions and figures. Missing metrics stay blank.
4. Confirm and save. Complete only the gaps that could change the next decision. The latest 7d gaps come first.
5. Review one learning and one next move. Keep or revise the plan yourself through the existing Diagnosis workflow.

The routine request asks for at most five newly eligible uploads at the selected checkpoint, plus complete verified corrections. If a backlog remains, repeat after saving. It does not automatically fetch anything from YouTube. Existing starting and operating baseline history is retained.

24h is an early look; 48h is optional investigation; 7d is the main review; 28d informs the next topic or format. Review normals monthly or after 4–6 matured uploads. The existing engine uses four eligible new uploads or its monthly review condition, not calendar time alone, to update an operating baseline. Use comparable dated 90-day channel periods for channel progress and distinct rolling 28-day snapshots for audience direction.

## What is available, and what may need manual work

| Information | First route | When missing |
|---|---|---|
| Views, Engaged views, impressions, CTR | Ask Studio; verify the exact-age report | Video Analytics / Advanced Mode; keep both view definitions separate |
| APV and AVD | Ask Studio for the exact checkpoint | Video Engagement / Advanced Mode; do not derive one from the other |
| Exact 0:30 Intro retention | Ask Studio only if it can access an exact reported value | Video Engagement → retention / Intro; never estimate a graph or use APV as 0:30 |
| Browse, Suggested, Search, External mix | Same-video, same-age Traffic source report | Advanced Mode; do not copy a whole-channel or lifetime mix into a video checkpoint |
| Monthly audience and New / Casual / Regular / Returning | Audience report, rolling 28 days | Save the actual processed as-of date; segments are not a person-by-person funnel |
| Average views per viewer | Advanced Mode for the same period | Leave missing if unavailable; repeat plays do not prove multiple distinct videos watched |
| New-upload vs older-library contribution | Advanced Mode with exact dates and publication groups | Keep missing unless both parts can be isolated correctly |
| Goal, intended video job, audience fit, planned uploads/capacity | Your strategy and plan | Studio cannot decide these for you |
| Qualified leads, bookings, sales | CRM / booking / sales records | Do not infer them from views or subscribers |

Ask Studio supports performance questions, but does not guarantee every report/field or machine-readable output. A well-formatted answer is not proof that a number was measured. Verify important results against the report. Native lifespan comparisons explicitly document first 24 hours, 7 days and 28 days. Ask for first 48 hours only if that exact report is retrievable; rolling last-48-hour realtime is a different measurement.

## Interpretation
A large result with softer rates stays a win with learning questions. Wider reach or different source mix may explain rate changes. Missing data is not a healthy verdict. Inspect the retention curve before claiming an opening failure. One video is a clue, not a repeated channel diagnosis. The numeric bands are review heuristics, not proof of cause or statistical significance.

Current creator normal and the normal used for a particular video can legitimately differ: the latter excludes that upload and later uploads, and uses compatible earlier measurements. Expand “Which normal is this video using?” to inspect the comparison group. Existing baseline history remains available.
